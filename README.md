
# LinkedIn Profile Card Generator

A browser-based tool to create a styled profile card 
with your LinkedIn link, bio, and personal description.

## 🔗 Live Demo
https://stupendous-florentine-94571d.netlify.app/

## 🛠 Built With
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Enter name, role, bio & LinkedIn URL
- Generates a styled profile card instantly
- Copy LinkedIn URL with one click
- Runs 100% in the browser
